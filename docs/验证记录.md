## 3. 机制验证（代码级）

- 反查 `org.eclipse.osgi_3.21.0.v20240717-2103.jar` 内 `org/eclipse/osgi/util/NLS.class` 的常量池：同时引用 **`osgi.nl`** 与 **`Locale` / `getDefault`** —— 即 NLS 以 `osgi.nl` 系统属性（缺省回落到 JVM 默认区域）决定加载哪份 `messages` 资源。
- 因此本项目在 `stm32cubeide.ini` 同时写入两条：`-nl zh_CN`（框架/平台层）与 `-Dosgi.nl=zh_CN`（JVM 系统属性，正是 NLS 读取的那条）。
- 片段包（`Fragment-Host`）不带版本范围，宿主类加载器可直接看到其中的 `<资源名>_zh_CN.properties`。
- Java `ResourceBundle` 在 `zh_CN` 下按 `_zh_CN` → `_zh` → 基准 依次查找，并把更通用的包设为父包 —— 因此**只译一部分也能生效**，未覆盖的键自动回退，不会出现空白或乱码。

## 6. 尚未覆盖的残余与原因

工程向导的 `STM32 Project`、`STM32 Project from an Existing STM32CubeMX Configuration File (.ioc)` 两条菜单标签仍为英文。已定位到原因：

- 这两条字符串通过该插件的 **`fragment.xml` + `fragment.properties`** 对外化（`Bundle-Localization: fragment`），键为 `projectcreation.wizard` / `projectcreation.fromioc.wizard`；
- 我们的片段包里**确实有**这两条键的中文（`fragment_zh_CN.properties` 内 `projectcreation.wizard=STM32 工程`），且用 IDE 自带 JDK 写的 `ResourceBundle` 探针（宿主包 + 片段包组类加载器）在 `zh_CN` 与 `zh` 下都能命中中文；
- 但实测 Eclipse **不会**从外挂片段包取用 `fragment_zh_CN.properties` 覆盖，而同样机制下 `plugin.properties` 类（如 CMake 插件）可以生效；
- 全库清点：50 个待译插件中只有 **6 个** 用 `fragment.properties`（58 个用 `plugin.properties`），且 ST 自己也没有发行任何 `fragment_zh*`/`plugin_zh*` 文件。受影响范围有限，主要是新建工程向导的菜单标签。

**要吃掉这点残余**：把中文直接写进这 6 个插件 JAR 内部（生成 `fragment_zh_CN.properties` 并回写 JAR，带 `.bak` 备份与一键还原）——属安装目录写入，需获授权，与「方式三」一并做。

**另需说明**：ST 自带的 37.5% 中文来自 Java NLS 的 `messages_zh.properties` 与 `OSGI-INF/l10n/bundle_zh.properties`；本机 IDE 的 `osgi.nl` 本来就是 `zh_CN`，因此这部分此前应已在生效（这也是「IDE 明明是英文的」并非源于区域设置的原因）。

## 7. 复核方法（30 秒）

1. 菜单栏是否中文 → 检验 Babel 平台层；
2. `文件 > 新建` 中 `STM32 CMake 工程`、`源文件夹`、`类` 是否中文 → 检验自建片段包；
3. `STM32 Project`（工程向导）仍英文 → 即第 6 节所述残余。

## 8. 完整安装（方式三）实测与两处缺陷修复（2026-10-08 晚）

走 `工具\安装汉化.ps1` 装入 `C:\stm32ide` 后，**桌面快捷方式（无参数直接启动 exe）**实测为中文：菜单栏、项目资源管理器、欢迎页动作均为中文；`STM32 Project` 两条仍英文（即第 6 节残余）。过程中修掉两个会导致「装了也没中文」的缺陷：

1. **`-nl` 位置错误**：安装脚本把 `-nl zh_CN` 插到了 `-vmargs` 之后，被当作 JVM 参数吞掉，启动器实际未收到中文区域。日志实证：`Command-line arguments: -os win32 -ws win32 -arch x86_64`，无 `-nl`。已修正为 **`-nl zh_CN` 置于 `-vmargs` 之前**，`-Dosgi.nl=zh_CN` 置于其后。
2. **dropins 不被 p2 接管**：安装并重启后 `dropins\stm32cubeide-zh\` 里的包不会并入配置——`bundles.info` 仍为 438 行、0 条 `nl_zh`（p2 清单目录时间戳未变，日志无 reconciler 记录），界面依旧英文。已改为安装时**直接把 473 个中文包写进 `<IDE>\configuration\org.eclipse.equinox.simpleconfigurator\bundles.info`**（绝对 `file:` URI，以 `.zhbak` 备份为母本重建、幂等），重启后即生效（911 行、473 条 `nl_zh`）。

`还原英文.ps1` 同步支持：从 `.zhbak` 恢复 `stm32cubeide.ini` 与 `bundles.info`。
