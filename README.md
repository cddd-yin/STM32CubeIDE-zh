# STM32CubeIDE 汉化

STM32CubeIDE（实测 1.19.0，Eclipse 2024-06 / 4.32）界面汉化——**走 Eclipse 官方语言包机制，不碰二进制、不反编译**。

## 怎么装？（新手照做即可）

> 全程只需三步，**不用装任何东西**。装完从桌面图标打开 STM32CubeIDE 就是中文。

### 第 1 步：把这个仓库下载到电脑

在页面右上角点绿色的 **`Code`** 按钮 → 选 **`Download ZIP`** → 下载后**解压**到任意文件夹（例如桌面）。
解压后应能看到 `一键安装汉化.bat`、`工具`、`成品` 等文件。

> 提示：如果不会解压，右键压缩包 → 用系统自带的「全部解压缩」即可。

### 第 2 步：双击 `一键安装汉化.bat`

- 弹出「是否允许此应用对你的设备进行更改？」→ 点 **`是`**（写入安装目录需要管理员权限，脚本会自动请求）。
- 脚本会**自动找到** STM32CubeIDE 安装目录并安装汉化；实在找不到时，会提示你粘贴安装目录
  （右键桌面 STM32CubeIDE 图标 →「打开文件所在位置」→ 复制地址栏即可）。
- 看到 `[√] 安装完成` 即成功。

### 第 3 步：打开 STM32CubeIDE

从桌面快捷方式（或开始菜单）启动，界面即为中文。

> **想还原英文**：双击 `一键还原英文.bat`（同样点一次「是」），完全恢复原状。
> **安装时提示软件正在运行**：先完全关闭 STM32CubeIDE 再双击一次。
> **不想往安装目录写文件**：见下方「方式一：零写入汉化启动」。

## 常见问题

| 现象 | 原因 | 解决方法 |
|---|---|---|
| 双击 bat 弹「Windows 已保护你的电脑」 | SmartScreen 对未签名脚本的常规拦截 | 点「更多信息」→「仍要运行」 |
| 双击后窗口一闪而过 | 脚本报错退出（少见） | 右键 `一键安装汉化.bat` →「以管理员身份运行」重试；仍失败请带截图反馈 |
| 提示「未能自动找到 STM32CubeIDE 安装目录」 | 安装位置非常规 | 按提示粘贴安装目录：右键桌面图标 → 打开文件所在位置 → 复制地址栏 |
| 提示「STM32CubeIDE 正在运行」 | 脚本防止改配置时文件被占用 | 完全关闭 STM32CubeIDE 后重试 |
| 杀毒软件弹窗/拦截 | 脚本要写安装目录下的配置文件 | 允许/信任即可；全部脚本为纯文本可自行审阅 |
| 打开还是英文界面 | 配置未生效 | 确认安装时提示 `[√] 安装完成` 后**重新打开**软件 |
| 想彻底卸载汉化 | — | 双击 `一键还原英文.bat`，删除汉化包并恢复全部配置，无残留 |
| 菜单里个别词还是英文（如 `Recent Files`） | 官方 Babel 中文包停更于 Eclipse 4.26，本 IDE 为 4.32 | 已知限制，新增文案回退英文，不影响使用 |

### 安全说明（为什么可以放心用）
- 走 Eclipse 官方 **NLS 语言片段机制**：只往 `dropins\` 放中文语言包、往配置清单注册、加一行 `-nl zh_CN`，**不改任何程序文件（exe/jar/DLL 一律不碰）**；
- 安装前自动备份启动配置与包清单为 `.zhbak`，还原脚本可完全恢复原状；
- 全部脚本为 PowerShell 纯文本，可自行审阅。

## 用法（进阶）

三种方式任选其一：

### 方式一：零写入汉化启动（不改安装目录任何文件）
双击 `工具\以汉化启动-零写入.cmd`。首次会自动生成 `runtime\` 独立配置环境（约 50 MB，几秒钟），之后 IDE 用仓库里的配置目录启动，效果与完整安装一致；仓库移动或换机后会自动重新生成。不想要了直接删 `runtime\` 目录即可。

### 方式二：零改动启动（只启用 ST 自带中文）
双击 `工具\以中文启动.cmd`：仅以 `-nl zh_CN` 启动。只能看到 ST 自带的 37.5% 中文（FreeRTOS 任务/队列/信号量视图、SWV、Live Watch、Fault Analyzer、下载/调试启动等），菜单栏仍是英文。

### 方式三：完整安装（推荐，桌面图标直接中文）
双击根目录 `一键安装汉化.bat`（新手入口，自动提权 + 自动定位安装目录）。脚本会：
1. 备份 `stm32cubeide.ini` → `.zhbak`、`bundles.info` → `.zhbak`；
2. 把 38 个自建片段包与 5 个 Babel 包释放到 `<IDE>\dropins\stm32cubeide-zh\`；
3. 把 473 个中文包注册进 `<IDE>\configuration\...\bundles.info`（实测本产品的 p2 **不接管 dropins**，只放 dropins 不会生效，必须写进包清单）；
4. 在 `stm32cubeide.ini` 的 **`-vmargs` 之前**写 `-nl zh_CN`（启动器参数），在 `-vmargs` 之后写 `-Dosgi.nl=zh_CN`（JVM 参数）。

`工具\安装汉化.cmd` 为等价入口；还原用 `一键还原英文.bat`。

### 维护与再生成

```
powershell -ExecutionPolicy Bypass -File 工具\导出词条.ps1     # 重抽文案（换版本后）
powershell -ExecutionPolicy Bypass -File 工具\生成语言包.ps1   # 由词库重编译片段包
```

词库直接改 `词库\zh\*.tsv`（`英文原文<TAB>中文`，与 `st_strings.tsv` 的 `en` 列精确对应），重跑生成脚本即可。IDE 升级后重复这两步即可重新适配，**不因版本变化而失效**。

## 原理（30 秒版）

STM32CubeIDE 是 Eclipse RCP 应用，汉化走 Eclipse 官方 **NLS 语言片段（`nl_zh`）** 机制：把中文资源以「片段包」形式挂在宿主插件上，启动时加 `-nl zh_CN` 即生效。共两层：

| 层 | 内容 | 来源 |
|---|---|---|
| Eclipse / CDT 层 | 平台、SWT、JFace、帮助、团队、C/C++ 编辑器与构建 | Eclipse 官方 **Babel** 中文语言包（R0.20.0） |
| ST 自有层 | 82 个 `com.st.*` 插件（SWV、FreeRTOS、ThreadX、构建分析器、工程向导等） | ST **自带中文 37.5%** ＋ 本项目**自建片段包补齐 94.7% 缺口** |

原理与兼容性分析见 `docs\原理与兼容性.md`，实测数据见 `docs\验证记录.md`。

│  ├─ st_strings.tsv         从 82 个 ST 插件抽出的 1544 条文案（英文 / ST 自带中文 / 缺口标记）
│  ├─ st_strings.summary.tsv 逐插件条数与缺口统计
│  └─ zh/                    中文词库（en<TAB>zh，按主题分三份，可继续增补）
├─ 工具/

│  ├─ 安装汉化.cmd / .ps1    完整安装（自动提权 + 备份 + dropins + 注册清单）
│  ├─ 还原英文.cmd / .ps1    一键还原
│  ├─ 以中文启动.cmd / .ps1   零改动启动（只启用 ST 自带中文）
│  ├─ 以汉化启动-零写入.cmd / 以零写入启动.ps1   零写入启动（runtime 缺失自动生成）
│  ├─ 生成零写入运行环境.ps1  生成 runtime\ 独立配置环境
│  ├─ 导出词条.ps1           从插件 JAR 抽取文案，区分英文与 ST 自带中文
│  └─ 生成语言包.ps1         由词库编译出 nl_zh 片段包
└─ 成品/

（根目录另有 `runtime\`：「零写入」启动用的独立配置目录，约 50 MB，属可再生成物，已由 `.gitignore` 排除、不入库。）

## 覆盖情况

| 项目 | 条数 |
|---|---|
| ST 自有 UI / 提示文案 | 1544 |
| ST 自带中文（本项目仅需启用） | 578（37.5%） |
| ST 未译缺口 | 966（738 条独立文案） |
| 本项目已补齐 | 915（占缺口 94.7%） |
| 自建片段包 | 38 个 |
| Eclipse/CDT 层 | 由 Babel 官方包覆盖（非本项目翻译） |

未收录的少量文案（约 51 条，主要是 MPU/OpenSTLinux 与个别内部提示）回退为英文，不影响使用。

## 已知限制

- **`fragment.properties` 类插件仍为英文**：50 个有待译缺口的插件里有 6 个把界面文案放在 `fragment.properties`（配合 `fragment.xml` 扩展声明），实测 Eclipse 不会从外挂片段包里取用它们的 `fragment_zh_CN.properties` 覆盖（而 `plugin.properties` 类可以，已实测 `STM32 CMake Project → STM32 CMake 工程` 生效）。受影响的主要是「新建工程向导」的菜单项标签。
- **Babel 版本差**：官方中文包停更于 R0.20.0（Eclipse 4.26），本 IDE 为 4.32。片段包无宿主版本约束，可正常挂载；4.26 之后新增的界面词条无中文，回退英文（例如「文件」菜单里的 `Recent Files`）。
- **不翻译的内容**：器件型号、`-fxxx` 编译选项、`VFPv3-D16` 等硬件特性名、URL、版本号保持原文，符合工程习惯。
